# Chapter 10 - Entity Framework Core Project

## Project Overview
This project demonstrates working with Entity Framework Core in .NET applications.

## Project Structure
- `WorkingWithEFCore/` - Contains Entity Framework Core related code and examples
- `docs/` - Project documentation and task tracking

## Getting Started
1. Clone the repository
2. Open the solution in Visual Studio or your preferred IDE
3. Restore NuGet packages
4. Build the solution

## Documentation
- [Architecture](docs/ARCHITECTURE.md) - System design and architecture decisions
- [Development](docs/DEVELOPMENT.md) - Development setup and guidelines
- [Tasks](docs/TASKS.md) - Current and upcoming tasks

## Development Guidelines
- Follow C# coding standards
- Use meaningful commit messages
- Create feature branches for new tasks
- Update documentation when making significant changes

## Requirements
- .NET 9.0 or later
- Entity Framework Core
- Visual Studio 2022 or later (recommended)
